# PurplePhoenix FVTT Tools

A collection of small quality-of-life modules for Foundry VTT.

## Features

- **HP in Bar**: Displays numerical HP values inside the token health bar on the canvas (mainly for D&D 5e). Font size, color, and outline are customizable in the settings.
- **Easy Flip Token**: Adds a keybinding (`F` by default) to easily flip the currently selected token(s) horizontally. Players can only flip tokens they own, while the Game Master can flip any token.
- **Simple Light**: Adds a new button to the Token HUD to quickly open a window with a list of common D&D light sources (e.g. Torch, Lantern, Light Cantrip) to apply them instantly to the token.
